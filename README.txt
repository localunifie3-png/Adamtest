Professional Education Login Demo
==================================

Files:
- index.html
- style.css
- script.js
- background.png
- ministry-logo.png

The provided artwork is used as the background.
The uploaded ministry logo is used inside the sign-in card.

The interface uses an original implementation of smooth, modern multi-step sign-in animations inspired by contemporary Microsoft-style UX. It is not a copy of Microsoft's proprietary UI or assets.

Open index.html to run it locally.

Updated version: softer rounded card/button, translucent background veil, smoother step transitions, focus motion, hover/press micro-interactions, and transparent ministry logo.
